## Getting Started Is Free and Takes 5 Minutes

```bash
git clone https://github.com/Ekaanth/OpenCut-AI.git
cd OpenCut-AI
cp apps/web/.env.example apps/web/.env.local
docker compose up -d
bun install && bun dev:web
```

Open `http://localhost:3000`. Drop in a video. Click transcribe. Start editing by text. It's that simple, and it's that free.
